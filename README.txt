PETALS & CRUMBS WEBSITE

Files:
- index.html       Home page
- collections.html Collections page
- customize.html   Custom gift request form
- admin.html       Admin demo for updating customer delivery tracking
- feedback.html    Feedback and inquiries form
- login.html       Sign-in page
- register.html    Account registration
- settings.html    Profile, billing, delivery, tracking and payment settings
- about.html       About page
- css/style.css    Responsive styles and colour palette
- js/script.js     Mobile navigation, copyright year, forms and browser-stored account settings

HOW TO RUN:
1. Extract this ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Keep the css and js folders beside the HTML files.

NOTES:
- Images load from Unsplash and require an internet connection.
- Gift request forms display a confirmation but do not save orders or send email. Pictures selected on the customize form are previewed locally only; they are not uploaded or saved. The feedback form also only displays a confirmation and does not send or store feedback.
- Account details and delivery information are stored in browser local storage. Customers can view, but not edit, their order tracking details. Open admin.html to update a registered customer's status, courier, tracking number and link. The admin page is a local demo with no administrator authentication; its updates are limited to the same browser's local storage and do not sync with a courier or other devices. Passwords are not stored or securely verified, and there is no real authentication or payment processing. Do not enter real passwords, full card numbers, or security codes.
- The Location footer link opens a Google Maps search for Petals & Crumbs; it is not a verified business address.
- Prices are sample prices in Malaysian Ringgit (RM).
